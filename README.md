#  Current Sensor Integration with the KiwisIoT Platform

## 📌 About the Project

Current Sensor Integration with the KiwisIoT Platform is an IoT-based project designed to measure and monitor electrical current consumption in real time.

Using a microcontroller and a suitable current sensor, the system measures the current flowing through an electrical circuit or connected appliance. The collected sensor readings are transmitted through Wi-Fi to the KiwisIoT platform.

Users can visualize and monitor real-time current measurements through the KiwisIoT online dashboard from anywhere. This helps users understand electrical usage, monitor connected appliances, and identify unusual changes in current consumption.

This project demonstrates how IoT technology can support smart energy monitoring, electrical system analysis, and efficient power management.
